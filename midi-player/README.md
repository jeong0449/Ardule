# Ardule MIDI Player

**Ardule MIDI Player** is a lightweight, web-GUI-based Standard MIDI File player with a dedicated **Channel 10 drum-roll view**.

It plays MIDI files through FluidSynth while displaying the drum performance in a browser-based graphical interface. The player is designed both for ordinary MIDI playback and for quickly inspecting the rhythmic structure of MIDI drum performances.

Ardule MIDI Player is part of the **Ardule** project.

## Features

- Standard MIDI File playback
- Web-based graphical user interface
- Channel 10 drum-roll visualization
- Bar and beat grid display
- Instrument labels for GM percussion notes
- Playback-position highlighting
- Full Mix mode
- Drums Solo mode — Channel 10 only
- Drums Mute mode — all channels except Channel 10
- Tempo adjustment during playback
- Pause and resume
- File browsing and drag-and-drop loading
- FluidSynth-based MIDI synthesis
- General MIDI compatible SoundFont support
- Self-contained Windows distribution using PyInstaller

The MIDI display is read-only. Ardule MIDI Player is intended as a player and viewer rather than a MIDI editor.

## Windows Distribution

The Windows distribution is provided as a standalone folder containing the executable and all runtime components required for MIDI playback.

Typical distribution layout:

    ArduleMIDIPlayer/
    ├── ArduleMIDIPlayer.exe
    ├── ardule-midi-player-demo.mid
    ├── _internal/
    ├── fluidsynth/
    ├── soundfont/
    └── licenses/

No Python installation is required to run the distributed Windows version.

Simply run:

    ArduleMIDIPlayer.exe

The graphical interface will open in your default web browser.

## Drum Channel Controls

Ardule MIDI Player treats **MIDI Channel 10** as the percussion channel according to the General MIDI convention.

Three playback modes are available:

- **Full Mix** — play all MIDI channels
- **Drums Solo** — play Channel 10 only
- **Drums Mute** — play all channels except Channel 10

This makes it easy to listen to a complete MIDI arrangement, isolate its drum performance, or hear the arrangement without drums.

## Finding Freely Distributable MIDI Files

Additional MIDI files suitable for redistribution can be found at the **Mutopia Project**:

https://www.mutopiaproject.org/

Mutopia provides downloadable MIDI files for many classical works.

Licensing varies by individual item, so always check the **Copyright** information on the page for a particular piece before redistributing its MIDI file. Many items are explicitly marked as Public Domain.

Note that classical MIDI files often contain no Channel 10 percussion track. They can therefore be useful for testing general MIDI playback but may not demonstrate the drum-roll features of Ardule MIDI Player.

## Building the Windows Version

Python and PyInstaller are required to build the Windows executable.

From PowerShell in the `midi-player` directory:

    .\build-windows.ps1

If local PowerShell execution policy prevents the script from running, it may be enabled for the current PowerShell process only:

    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Then run:

    .\build-windows.ps1

The build script:

1. removes previous `build/` and `dist/` directories;
2. builds `ArduleMIDIPlayer.exe` using PyInstaller in `onedir` mode;
3. copies FluidSynth;
4. copies the SoundFont;
5. copies third-party license files;
6. places `ardule-midi-player-demo.mid` directly beside the executable.

The resulting distribution is created under:

    dist/ArduleMIDIPlayer/

## Why a Web GUI?

Ardule MIDI Player uses a local web interface while MIDI parsing and playback are handled by the Python application and FluidSynth.

This approach combines a lightweight desktop launcher with the flexibility of HTML, CSS, JavaScript, and SVG for visualization. It also makes a relatively rich drum-roll display possible without requiring a conventional desktop GUI framework.

The browser is the interface; the MIDI file remains local.

## Ardule

Ardule is an experimental family of projects exploring MIDI playback, drum patterns, embedded musical devices, and tools for studying and reusing rhythmic information.

Ardule MIDI Player complements the drum-pattern-oriented tools in the project by providing a simple way to play and inspect Standard MIDI Files, with particular attention to their Channel 10 drum performances.
